3. Considerado e deliberadamente NÃO alterado (com justificativa)

  • Schema global Attorney/WebSite (em _pages-data.json): é a reprodução fiel do <head> aprovado do site. Adicionar sameAs exigiria perfis sociais reais (não inventar) e mexer no SEO já aprovado — mantido.
  • SearchAction (sitelinks searchbox): o site não possui busca interna; declarar a ação seria schema inválido — corretamente ausente.
  • hreflang: site monolíngue (pt-BR) — não se aplica.
  • preconnect/dns-prefetch para GA/Clarity: analytics é carregado após consentimento e de forma diferida; pré-conectar a domínios que podem nunca ser usados (consentimento negado) não é claramente superior — mantido como está.
  • OG image por página: exigiria geração de imagens; fora do escopo de “não alterar a identidade visual”. Fica como sugestão futura.

4. Validação

npx astro check → 0 erros / 0 warnings / 0 hints. npm run build → 159 páginas, 157 URLs (idêntico à sprint anterior; nenhuma URL alterada). Schema de artigo verificado no HTML compilado.

5. Ganhos esperados

  • SEO / Rich Results: artigos agora elegíveis a rich results de BlogPosting com imagem, datas e publisher completos.
  • EEAT: autoria vinculada ao perfil do advogado (/o-escritorio/) e publisher com logo reforçam confiança/atribuição.
  • Frescor: dateModified sempre presente é um sinal usado na avaliação de conteúdo.
  • CWV / Ads: sem regressões — o projeto já era estático, leve e sem CLS; a mudança é apenas de metadados (peso desprezível).

6. Sugestões para uma terceira rodada

  • Imagens Open Graph por página (geração automática no build) para melhor CTR em compartilhamentos e Ads.
  • Datas visíveis de publicação/atualização nos artigos (hoje no schema; exibi-las reforça EEAT ao leitor) — pequena adição visual, a validar com você.
  • Perfil do autor em /o-escritorio/ com Person + knowsAbout + foto (ImageObject) — aprofunda a autoria.
  • Busca interna (habilitaria SearchAction/sitelinks searchbox).
  • Medição real de PageSpeed em produção após o deploy, para calibrar preloads finos se necessário.
